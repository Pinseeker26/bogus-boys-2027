Bogus Boys 2027 — fixed flights prototype

Open commissioner.html to add players and assign their fixed season flight (A or B). Open index.html to check in as a registered player. Open weekly-results.html to see the flight-specific roster. The same browser stores the demo state in localStorage.

IMPORTANT: This is a LOCAL DEMONSTRATION ONLY. There is no shared database, authentication, server-side authorization, real attendance, or scoring integration. Do NOT publish the commissioner controls for real league use. A production implementation must use a backend with player login, commissioner permissions, persistent player IDs, per-week attendance, per-week flight snapshots, audit history, and secure database writes. The current demo only shows one current-week roster.

The original 2026 Weekly Results page is preserved as weekly-results-2026-reference.html. Other legacy pages remain untouched.
