BOGUS BOYS 2027 — LEAGUE SETTINGS & SCHEDULE
Open commissioner.html, then select League Settings & Schedule.
Set course, day, start time, number of regular-season weeks (1–52), weekly dates, format overrides, cancellations, signup closures, and four playoff dates.
Save. Home check-in, This Week, Weekly Results, and Commissioner HQ use the configured number of regular-season weeks.
Attendance remains independent per week; changing season length does not erase old attendance/results (they remain in storage).
The default regular season is 20 weeks plus 4 separate playoff rounds.
Data is saved only in local browser storage. The export/restore backup now includes settings.
Automatic attendance deadline by hours is a stored setting only, not enforced in this prototype.
Playoff dates are stored but the existing playoff calculator has not been converted to a calendar-driven system.
The commissioner/assistant role preview is NOT secure access control. Do not publish publicly.
